# 阳宅风水 · 八宅命卦测算

一个关于中国传统阳宅风水文化的纯静态网站,基于《八宅明镜》《阳宅三要》的八宅法:

- **命卦测算** — 按出生日期与性别推算命卦(东四命 / 西四命),附四吉方、四凶方与罗盘方位图
- **宅向吉凶** — 选择房屋坐向,生成八宅吉凶方位罗盘图与门、主、灶布局建议
- **风水知识** — 十二则常见阳宅禁忌与化解方法
- **关于** — 阳宅风水文化简介与理性提示
