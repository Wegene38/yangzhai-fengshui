# 阳宅风水 · 八宅命卦测算

一个关于中国传统阳宅风水文化的纯静态网站,基于《八宅明镜》《阳宅三要》的八宅法:

- **命卦测算** — 按出生日期与性别推算命卦(东四命 / 西四命),附四吉方、四凶方与罗盘方位图
- **阳宅罗盘布局工具**([luopan.html](luopan.html)) — 拖动罗盘选房屋朝向,自动生成九宫格布局建议(主卧、儿童房、书房放吉方;厨房、卫生间压凶方),附「户型不是九宫格怎么办」立极方法,支持添加到手机主屏幕(PWA manifest)
- **日照模拟器**([sunlight.html](sunlight.html)) — 设置纬度与朝向,按太阳赤纬/时角公式模拟一年四季:正午阳光进屋深度剖面图、一天之中晒到房子哪一侧的俯视图、朝向墙面日照时长与楼间距参考
- **风水知识** — 十二则常见阳宅禁忌与化解方法
- **关于** — 阳宅风水文化简介与理性提示
