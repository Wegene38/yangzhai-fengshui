# 阳宅风水 · 四大门派在线分析

一个关于中国传统阳宅风水文化的纯静态网站。**进入首页先选门派**,各门派均为交互式分析,支持上传自己的户型图:

## 四大门派

- **八宅派**([luopan.html](luopan.html)) — 命卦测算(东四命/西四命)+ 拖动罗盘选朝向,自动生成九宫格布局建议;支持上传户型图自动点评每个房间
- **峦头派(形法)**([luantou.html](luantou.html)) — 看环境山水:按方位勾选靠山、明堂、路冲、反弓、天斩等要素,实时生成吉凶报告与化解
- **玄空飞星派(三元)**([xuankong.html](xuankong.html)) — 按建造/入住年份定元运,自动排九宫飞星盘(天元龙顺逆飞),识别旺山旺向/上山下水,逐宫解释山向星宜忌
- **金锁玉关派(过路阴阳)**([jinsuo.html](jinsuo.html)) — 八方逐个标「砂/水」,按「一二十四要砂、六七八九要水」口诀评分,给人造砂水建议

## 通用工具

- **户型图标注**([upload.html](upload.html)) — 上传户型平面图(仅本地处理),拖动立极点、旋转指北、点选标记房间/砂水/窗外环境,**四派分析自动读取**
- **日照模拟器**([sunlight.html](sunlight.html)) — 互动式:拖动太阳绕房子走看影子与受光面,上下拉太阳看光照进屋深度
- **禁忌化解 / 关于** — 各派通用禁忌与门派简介

## 安装到桌面 / 主屏幕(PWA)

网站支持安装为本地 App:

- **电脑 Chrome / Edge**:地址栏右侧点「⊕ 安装」,或在页面右上角点「📥 安装」
- **iPhone / iPad(Safari)**:点底部分享按钮 →「添加到主屏幕」
- **Android(Chrome)**:菜单 →「添加到主屏幕 / 安装应用」

安装后全屏独立运行(由 `manifest.webmanifest` + `sw.js` 离线缓存支持,断网也能用)。

## 技术

纯 HTML / CSS / JavaScript,无构建步骤、无外部依赖(可在国内直接访问)。户型图不上传服务器,全本地处理。

## 本地运行

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## 部署(GitHub Pages)

仓库 Settings → Pages → Source 选 `main` 分支 `/ (root)` 即可。
